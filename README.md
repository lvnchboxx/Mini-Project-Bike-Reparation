# Mini Bike Reparation App

Mini Bike Reparation App is a Flutter mobile application for requesting and managing bike repair services. Users can log in, create repair requests, track repair status, receive notifications, use GPS location, and store data using both a relational database and Firebase.

## Features

- User login and registration using Firebase Authentication
- Create, read, update, and delete bike repair requests
- Store repair request data in a relational database
- Store additional user-related data using Firebase
- Send notifications when repair status changes
- Use GPS location as a smartphone resource
- Simple and user-friendly Flutter interface

## Project Requirements

This project implements:

- CRUD with a relational database
- Firebase Authentication
- Firebase data storage
- Notifications
- Smartphone resource usage: GPS location


## App Description

The Mini Bike Reparation App helps users request bike repair services through a mobile application. Users can submit repair details, manage their requests, and track the repair status. The app uses Firebase for authentication and additional data storage, while repair request data is handled using a relational database.
